# NoteShare 📚

A student notes-sharing platform to upload, organize, and access academic study materials.

🌐 **Live Demo:** https://student-notes-sharin-q4sp.bolt.host

## Features

* Browse subjects and topics
* Upload and download study notes
* Organize academic materials
* User authentication
* Responsive user interface

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Supabase
